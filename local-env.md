# Knowledge Enrichment - Local Environment Config

This guide is designed to get you set up with a local development environment to begin using Hyland's Knowledge Enrichment API.

---

### Download / Install the following:

**Postman**  
An application that sends HTTP requests. 
[Download here](https://www.postman.com/downloads/)
- Once downloaded you'll need to create a free account, which can be done using the icon in the top-right corner of the Postman app.
